# Multimodal Molecular Property Prediction — hERG (TDC ADMET)

Predicts hERG channel blockade (binary classification) by combining three molecular
representations — SELFIES sequence (1D), molecular graph (2D), and a Boltzmann-weighted
3D conformer ensemble — via a gated multimodal fusion model. Includes a secondary
generalizability check on the AMES mutagenicity dataset.

## Installation

```bash
conda env create -f environment.yml
conda activate chemprop
```

Core dependencies: Python, PyTorch, PyTorch Geometric, RDKit, selfies, PyTDC, scikit-learn.

## Reproduction

Run notebooks in order. Each notebook reads only from `data/splits.json` and the
previous notebook's cached outputs — nothing depends on live kernel state from
another notebook.

```
01_data_and_eda.ipynb                  pulls hERG from TDC, writes data/splits.json
02_conformer_generation.ipynb          generates + caches conformers to data/processed/
03_train_1d.ipynb                      trains SELFIES Transformer
04_train_2d.ipynb                      trains GINEConv
05_train_3d.ipynb                      trains all 3 aggregation variants
06_train_multimodal.ipynb              trains concat + gated fusion
07_final_eval_and_leaderboard.ipynb    single held-out test evaluation, all models
08_multiseed_robustness.ipynb          5-seed rerun of core models
09_ames_reproduction.ipynb             generalizability check on AMES dataset
```

Notebooks 03 and 04 can be run in parallel; they don't depend on each other or on 02.

## Final Selected Model

3D-only, `learned_attention` aggregation — test AUROC 0.818 ± 0.033
(5-seed mean, TDC official protocol). See `experiments/multiseed/3d_learned_attention/`.
